# Stock-Market-Analysis
A Python project analyzing stock market trends using Yahoo Finance and Linear Regression
🔧 Features

Stock Data Extraction: Uses yfinance to fetch stock prices.

Exploratory Data Analysis: Visualizes closing prices and daily returns.

Moving Averages: Calculates and plots 50-day moving averages.

Stock Price Prediction: Uses Linear Regression to forecast stock trends.

Interactive Visualizations: Uses plotly for enhanced visuals.

🛠 Technologies Used

Python

Yahoo Finance API

Matplotlib & Seaborn (for visualization)

Plotly (for interactive charts)

Scikit-Learn (for regression analysis)
